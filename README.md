# Bioinformatics-internship-isabial
This repository contains the scripts I developed during my internship as a bioinformatics student at the Health and Biomedical Research Institute of Alicante (ISABIAL).

**Note:** For confidentiality and intellectual property reasons, this repository contains source code only. No project data, results, or sensitive information are included.
> **Note on Language:** This repository was originally developed and documented in Spanish during my internship at ISABIAL, and has been translated into English for international standardization and reproducibility (English  and Spanish version).

## Projects

### 1. [RNA-Seq Differential Expression Analysis Pipeline](./Análisis_Expresión_Diferencial_RNASeq)
* **Description:** R script that performs a complete differential expression analysis (DESeq2), followed by functional enrichment analysis (GSEA, GO, KEGG).
* **Skills:** `R`, `DESeq2`, `clusterProfiler`, `fgsea`, `ggplot2`, `pheatmap`.

### 2. [Clinical Data Processing and Analysis](./Procesamiento_Datos_Clínicos)
* **Description:** Script for data cleaning, merging, normalization, and exploratory analysis of clinical data and biomarkers from diverse sources.
* **Skills:** `R`, `dplyr`, `tidyr`, `corrplot`, `factoextra` (PCA).

### 3. [Automation of SRA Data Download and Quantification](./Automatización_Descarga_SRA)
* **Description:** Script to automate downloading FASTQ data from NCBI SRA using a BioProject ID and its downstream processing for expression quantification.
* **Skills:** `R`, `rentrez`, command-line automation (SRA-Toolkit, Salmon), `tximport`.
